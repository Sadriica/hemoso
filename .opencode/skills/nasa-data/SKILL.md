# NASA data and resources

1. Review the challenge's resources tab at
   https://www.spaceappschallenge.org/2026/challenges/ and record every NASA or
   partner-agency resource we use or consult.
2. For each one, in `docs/nasa_data.md`: name, link, what we take (a range, a
   risk, a magnitude) and which file of the solution uses it. Say what a dataset
   cannot support (for example, pre/post-flight samples are not daily series).
3. Base sources: Human Research Roadmap, HRP health risks, NTRS, OSDR.
4. Only list what we actually use. Do not list resources just to name them.
5. Hand the list to Bio 2 for the "NASA data" field of the submission page.
